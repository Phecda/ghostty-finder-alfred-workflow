# GhosttyFinder Alfred Workflow

An Alfred workflow to seamlessly jump between Finder and Ghostty.

## Features

- `fg`: Open current Finder folder in Ghostty (opens a new tab if Ghostty already has a window, or creates a new window).
- `gf`: Open current Ghostty working directory in Finder.

## Requirements

- macOS
- [Alfred](https://www.alfredapp.com/) with Powerpack
- [Ghostty](https://ghostty.org/) (version 1.3.0 or later, which provides native AppleScript scripting support)

## Installation

Download `GhosttyFinder.alfredworkflow` from [GitHub Releases](https://github.com/Phecda/ghostty-finder-alfred-workflow/releases) (or the latest GitHub Actions run artifacts) and double-click to install into Alfred.
